Privacy & keys

This page has no server. Your key and files go straight from your browser to the AI provider you chose, and GPS points go to OpenStreetMap for the road check. Nothing is sent to GitHub or to us.

The key is kept for this tab only, unless you tick "Remember", which stores it in this browser. Use a key with a spending limit.

Chat subscriptions (Claude Pro/Max, ChatGPT Plus, Gemini Advanced) don't include API access. Gemini offers a free-tier API key.
